# Ghostly 0.3.62

## Локальные прокси: работа с группой

- Выделяйте прокси флажками, с Ctrl или диапазоном через Shift. Можно выбрать все записи или снять выделение.
- Меняйте страну или конкретный сервер сразу у всей выбранной группы. При смене страны Ghostly старается сохранить протокол, транспорт и обычный/LTE-маршрут каждого прокси.
- Включайте и выключайте выбранные прокси и копируйте их адреса одним действием.
- В выборе сервера появился поиск. Поиск серверов понимает страну, её код, адрес, транспорт и несколько слов одновременно — например, «Германия grpc».
- Логины и пароли со специальными символами правильно сохраняются в копируемом адресе прокси.

## Подключение и удобство

- Быстрые изменения настроек туннеля накапливаются: после паузы примерно в 0,9 секунды применяется итоговая конфигурация. Серия правок больше не требует отдельного переподключения на каждое нажатие.
- Настройки обновлений, трея, автоматического восстановления, сторожа соединения и неактивные записи не вызывают лишний перезапуск туннеля.
- Исправлено определение применённых настроек после неудачного подключения и при ожидании другого переподключения.
- В разделе «О приложении» можно скопировать краткую диагностику для поддержки: версию, сеть, ядро и состояние VPN, без ссылок подписки, ключей и сырых журналов.
- Исправлен резервный адрес загрузки подписок, когда основной сайт недоступен.

## Обновления без лишней загрузки

- На Android автоматическая загрузка по умолчанию ждёт Wi-Fi или Ethernet. По мобильной сети обновление можно скачать вручную; ограничение отключается в настройках.
- Загрузку можно остановить и продолжить позже. Скачанная часть сохраняется и проверяется перед установкой.
- В клиент добавлен просмотр описания будущих обновлений перед скачиванием.
- Публикация поддерживает отдельную версию файла для каждой платформы: изменение только Windows не требует нового APK для Android, и наоборот.

## Windows: плавность и сцена

- Сокращены рывки сцены и переходов. Таймер сцены следует кадрам монитора, сияние рисуется крупными группами команд и переиспользуется для отражения.
- Изменён графический режим по умолчанию и ограничен графический кэш. Эффекты, сцена и анимации сохранены.
- Открытие из трея и повторный запуск выводят окно вперёд, в том числе когда оно уже открыто за другим окном.
- Сохранена прежняя форма очков призрака, линзы стали прозрачнее. Микрофон получил более крупный корпус, объёмную металлическую головку и детальную сетку.

## Хранение подписок

- Подписки на Windows защищены DPAPI с привязкой к пользователю, на Android — Android Keystore. Старые профили переносятся автоматически.
- Данные подключения локальных прокси больше не дублируются в обычном файле настроек: там остаётся привязка, а данные восстанавливаются из защищённого профиля.
- На Windows конфигурация Xray передаётся без временных файлов. Обычный экспорт отдельных серверных конфигураций подписок Ghostly отключён.
- В переносной Windows-версии на другом компьютере подписку нужно добавить заново: защищённое хранилище привязано к исходному пользователю Windows.
