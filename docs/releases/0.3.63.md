# Ghostly 0.3.63 — Android

Срочное исправление загрузки обновлений Android. Windows остаётся на 0.3.62: повторно скачивать установщик не нужно.

- Исправлена ошибка `ENOENT` при открытии временного APK, если папка кэша исчезла во время ожидания ответа сервера или перехода к другому зеркалу.
- Если исчезла уже скачанная часть APK, загрузчик один раз повторяет запрос к тому же зеркалу с актуальным смещением. Проверка SHA-256 сохраняется.
- Параллельная проверка обновлений больше не удаляет активную загрузку или APK, подготовленный для системного установщика.
- Сохранены все изменения 0.3.62.

Если установленная версия уже не может скачать обновление, скачайте APK по прямой ссылке и установите поверх приложения. Удалять Ghostly и подписку не нужно.
